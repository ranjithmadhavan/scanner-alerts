How to send to it from TradingView

In the alert's Notifications tab, tick Webhook URL and paste the URL. Whatever you put in the alert's Message is what's sent. Plain text arrives as it is; JSON arrives as one line per field, and is kept as JSON for trading on later. For example:

{"ticker": "{{ '{{ticker}}' }}", "action": "{{ '{{strategy.order.action}}' }}", "price": "{{ '{{close}}' }}", "time": "{{ '{{timenow}}' }}"}

Any tool that can POST to a URL works the same way. The URL is the key, so keep it private: if it gets out, make a new one. Up to 30 requests a minute and 10 KB each.
