How your receiver checks a request

Every request is a POST of JSON (with "version": 1) and these headers:

  • X-Signature: t=1730000000,v1=5257a8…: an HMAC-SHA256 of t, a dot and the raw body, keyed with the signing secret. While a secret is being rotated there are two v1 values; accept either.
  • X-Webhook-Timestamp: the same t. Refuse requests more than 5 minutes old, so a captured one can't be replayed.
  • X-Webhook-Id: the same on every retry of one delivery. Ignore an id you've already handled.
  • Your own header, if you set one, for receivers that only check a key.

A failed delivery (no answer, HTTP 429 or 5xx) is tried twice more, a few seconds apart. Answer with any 2xx once you have it.

import hashlib, hmac, time

def verify(raw_body: bytes, signature: str, secret: str) -> bool:
    parts = [p.split("=", 1) for p in signature.split(",")]
    t = dict(parts)["t"]
    if abs(time.time() - int(t)) > 300:
        return False  # too old: a replay
    expected = hmac.new(secret.encode(), t.encode() + b"." + raw_body, hashlib.sha256).hexdigest()
    return any(hmac.compare_digest(expected, v) for k, v in parts if k == "v1")
